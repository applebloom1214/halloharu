# 할로하루 HalloHaru

할로하루는 사용자가 하루를 가볍게 기록하고, 부담 없는 공감과 웃음을 주고받을 수 있는 하루 기록 서비스입니다.

## 배포

[할로하루 서비스 바로가기](https://halloharu.vercel.app)

## 프로젝트 목적

대부분의 SNS는 뛰어난 외모, 능력, 인맥, 화려한 일상처럼 보여줄 것이 많은 사람에게 유리합니다.

반면 평범한 일상을 보내는 사람들은 글을 올려도 충분한 반응을 받기 어렵고, 무플과 무관심이 반복되면 점점 기록의 흥미를 잃게 됩니다.

할로하루는 평범한 하루도 부담 없이 남기고, 가벼운 리액션으로 공감받을 수 있는 공간을 목표로 합니다.

## MVP 기능

- 회원가입 / 로그인
- 가벼운 하루 기록 작성
- 하루 기록 목록 보기
- 이모지 / 이모티콘 공감 리액션
- 내가 쓴 기록 보기
- 유머 공간 Coming soon 페이지

## 회원가입 및 이메일 인증 흐름

1. 사용자가 이메일과 비밀번호를 입력합니다.
2. Cloudflare Turnstile로 자동 가입 요청을 방지합니다.
3. Supabase Auth가 회원가입을 처리합니다.
4. Brevo SMTP를 통해 이메일 확인 링크를 발송합니다.
5. 사용자가 링크를 누르면 `/auth/confirm`에서 인증을 처리합니다.
6. 인증에 성공하면 서비스로 이동합니다.
7. 만료되거나 이미 사용한 링크는 인증 오류 페이지로 이동합니다.

로그인 과정에도 Cloudflare Turnstile CAPTCHA가 적용되어 있습니다.

## 비밀번호 재설정 흐름

1. 사용자가 로그인 페이지에서 비밀번호 재설정을 요청합니다.
2. Cloudflare Turnstile로 자동 요청을 방지합니다.
3. Supabase Auth가 비밀번호 재설정 요청을 처리합니다.
4. Brevo SMTP를 통해 비밀번호 재설정 링크를 발송합니다.
5. 사용자가 링크를 누르면 `/auth/confirm`에서 인증을 처리합니다.
6. 인증에 성공하면 `/update-password`로 이동합니다.
7. 사용자가 새 비밀번호를 입력하면 Supabase Auth에 저장합니다.
8. 변경 완료 후 로그아웃하고 새 비밀번호로 다시 로그인합니다.

## 로컬 실행 방법

### 1. 프로젝트 설치

저장소를 내려받은 후 프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
npm install
```

### 2. 환경 변수 설정

프로젝트 최상위 경로에 `.env.local` 파일을 만들고 다음 환경 변수를 설정합니다.

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
NEXT_PUBLIC_TURNSTILE_SITE_KEY=
```

실제 환경 변수 값은 Supabase와 Cloudflare Turnstile 대시보드에서 확인할 수 있습니다.

`.env.local`에는 외부에 공개하면 안 되는 값이 포함될 수 있으므로 Git에 커밋하지 않습니다.

### 3. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속합니다.
